## Risk register

| Risk | Mitigation |
|---|---|
| Circular imports between packages | Strict layering: core → webhook → backtest/dashboard; no back-edges |
| Import paths break (lots of `from bot.X`) | Add compatibility shim in old `bot/__init__.py` re-exporting from new packages; deprecate gradually |
| Tests break after move | Run full suite after each package move; fix path issues incrementally |
| Plan files reference old paths | Update plans/ as part of step 12 |
| `.gitignore` regression | Verify output/, __pycache__/, .venv still ignored after moves |
| Existing scripts (run.sh, capture-frozen-feed.py) | Update sys.path or use `pip install -e packages/smc_bot_*` so scripts import correctly |

## Rollback

Single revert commit (`git revert HEAD`); tree returns to current state.
